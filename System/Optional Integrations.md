# Optional integrations

## Colors for Folders Files and Tabs

The vault owner's plugin is an optional visual enhancement. This author
relationship is disclosed; core navigation, metadata, templates, and views do
not require it. Its official directory listed desktop support and Obsidian
1.14.4+ when checked on 2026-10-18. Recheck the listing before installation.

Install only through Obsidian's official community-plugin directory if you choose
it. Review its permissions and assign colors only to synthetic folders in this
template. Do not copy plugin state from a private vault or bundle binaries here.
The owner's ColorsTest vault and plugin deployment settings are independent and
are not prerequisites for this vault.

Source: [official plugin listing](https://community.obsidian.md/plugins/colors-for-folders-files-and-tabs).

## QMD later

No QMD collection, model download, index, or MCP service is configured for v1.
If added later, scope the collection to the chosen private vault, review network
and model-download behavior, exclude generated indexes from Git, and consider
what cached content survives note deletion. Do not index sibling directories.

Source: [QMD repository](https://github.com/tobi/qmd).
