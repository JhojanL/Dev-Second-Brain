# Reporting a security problem

Do not put credentials, employer information, or private notes in public issues.
This local template has no published vulnerability-reporting endpoint. Contact
the repository owner through an existing private channel, or use GitHub private
vulnerability reporting if the future repository enables it. No response-time
or maintenance commitment is implied.

If credentials were committed, rotate them immediately and review repository
history and distribution copies. See [the security guidance](System/Security.md).
